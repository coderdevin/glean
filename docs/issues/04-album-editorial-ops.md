# 切片 4 · 编辑运营：排序 + 逐篇编辑 + 导入进度/重试 + 封面

> 来源：`docs/prd-albums.md`。

## 构建内容

让编辑能把专辑运营起来：手动调整成员顺序、逐篇编辑成员 pick、查看某次导入的
进度与失败并重试、上传专辑封面。

- **排序**：admin 拖拽调整成员次序，写 `position_in_album`（默认导入序，可被
  覆盖）。
- **逐篇编辑**：复用现有 admin pick 编辑流程，改为 album-aware——编辑成员 pick
  的字段（标题/摘要/要点/分节/编者note）时不误改其 `album_id` 归属、也不把它
  推进每日流。
- **导入进度**：面板显示某专辑的排队 / 处理中 / 已发布 / 失败 计数（复用
  `submission_events` / status）。
- **失败重试**：复用现有 re-run，重试成功后进入专辑。
- **封面**：上传写 `cover_image_key`，在 `/album` 与详情页显示。

## 验收标准

- [ ] 拖拽排序后，详情页顺序随 `position_in_album` 变化。
- [ ] 能编辑某成员 pick 的字段并生效，且不改变其专辑归属、不误入每日流。
- [ ] 导入进度面板显示准确的排队/处理/发布/失败计数。
- [ ] 能重试失败文章，成功后成为专辑成员。
- [ ] 能上传封面并在 `/album` 索引与详情页显示。
